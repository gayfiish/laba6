## Тема

Веб-программирование на Python.

## Цель работы

Изучить основы веб-программирования с использованием Flask,
FastAPI, REST API и шаблонов Jinja2.

## Выполненные задания

### Средняя сложность

**№6. FastAPI «Hello»**

Создано приложение FastAPI с маршрутом GET /,
который возвращает приветствие в формате JSON.

**№8. FastAPI принимает параметр и отвечает**

Реализован маршрут GET /greet, принимающий
параметр name и возвращающий персональное приветствие.
При отсутствии обязательного параметра сервер возвращает 422.

**№2. Страница с формой (имя → приветствие)**

Создано приложение Flask с HTML-формой.
Данные передаются методом POST и обрабатываются сервером.
Для вывода результата используется шаблон Jinja2.

### Повышенная сложность

**№4. Загрузка файла через форму**

Реализована загрузка файлов через Flask.
Файлы сохраняются в папку uploads с уникальными именами.

Предусмотрены:
- Проверка допустимых расширений.
- Ограничение размера файла до 5 МБ.
- Обработка отсутствующего файла.
- Обработка ошибок сохранения.

**№10. Тестирование API pytest**

Созданы 11 автоматических тестов для FastAPI и Flask.

Проверяются:
- Ответы API и передача параметров.
- Обработка отсутствующих параметров.
- Отображение и отправка HTML-формы.
- Успешная загрузка файлов.
- Отклонение запрещённых форматов.
- Отсутствие файла в запросе.
- Превышение допустимого размера файла.

## Структура проекта

- `main.py` — приложение FastAPI.
- `flask_app.py` — приложение Flask.
- `templates/index.html` — HTML-страница с формами.
- `tests/test_api.py` — автоматические тесты.
- `requirements.txt` — зависимости проекта.
- `.gitignore` — исключения Git.

## Установка зависимостей

```bash
py -m pip install -r requirements.txt
```

## Запуск FastAPI

```bash
py -m uvicorn main:app --reload
```

Главная страница: http://127.0.0.1:8000

Документация Swagger: http://127.0.0.1:8000/docs

## Запуск Flask

```bash
py flask_app.py
```

Адрес приложения: http://127.0.0.1:5000

## Запуск тестов

```bash
py -m pytest -v
```

Результат локальной проверки: 11 тестов успешно пройдены.
